One ecosystem. Re-benchmarked for healthcare.

Same 9 pillars, same maturity model, same citation discipline as RICE-FSI — rebuilt objective by objective against HIPAA, HITRUST CSF, IEC 81001-5-1, and the gap in Malaysian digital-health regulation. Built as real-world exposure grows, not written speculatively.

§ 00 · WHY A SEPARATE EDITION

Same architecture. Different battlefield.

Financial services and healthcare share almost nothing operationally — but the governance discipline RICE encodes translates directly.

01

Patient data, not transaction data

PHI carries lifetime sensitivity a bank transaction doesn't — it can't be reissued like a compromised card number. Data Security objectives are rebuilt around that asymmetry.

02

IoMT is the new endpoint

Infusion pumps, imaging systems, and connected diagnostics don't behave like laptops. Infrastructure and Emerging Horizon objectives absorb IEC 81001-5-1 and FDA premarket cybersecurity requirements.

03

A regulatory gap, not a mature baseline

Malaysia has PDPA and an APHM private-hospital code of practice — but no dedicated digital-health security law. RICE-HC is built to fill exactly that gap, the same way RICE-FSI closed BNM RMiT's operational blind spots.

§ 01 · BENCHMARK SET

What RICE-HC is built against.

Global standards, dissected and merged into the same 9-pillar structure — with Malaysian context layered in where global standards stay silent.

HIPAA Security Rule

US — 2025 NPRM removes "addressable" flexibility; MFA, encryption, and segmentation move to mandatory. Finalizing ~2026.

HITRUST CSF

~1,800 controls consolidating 60+ standards into a certifiable healthcare-specific framework — the closest existing analogue to RICE's ambition.

IEC 81001-5-1 / FDA SPDF

Medical device and IoMT lifecycle security — secure product development, SBOMs, post-market vulnerability handling.

Malaysia PDPA + APHM CoP

Health data as "sensitive personal data" under PDPA; private-hospital code of practice — but no unified security mandate.

§ 02 · STATUS

All 9 pillars drafted. None yet validated.

Every pillar carries a full objective set, benchmarked against HIPAA, HITRUST CSF, IEC 80001-1/81001-5-1, and Malaysian PDPA. Every objective is marked DRAFT until it's been pressure-tested against real healthcare-sector engagement — that validation happens as exposure grows, not before.
